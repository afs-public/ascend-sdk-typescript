# SearchOpenLotsResponse

Response message containing a list of open lots. Please note that the response is sorted by acquisition date of an open lot adjusted for wash sales in ascending order, and also asset_id in ascending order.

## Example Usage

```typescript
import { SearchOpenLotsResponse } from "@apexfintechsolutions/ascend-sdk/models/components";

let value: SearchOpenLotsResponse = {};
```
