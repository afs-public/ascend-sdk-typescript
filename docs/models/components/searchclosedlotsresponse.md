# SearchClosedLotsResponse

Response message containing a list of closed lots. Closed lots are sorted in the response first by disposal_date ascending, then by asset_id ascending

## Example Usage

```typescript
import { SearchClosedLotsResponse } from "@apexfintechsolutions/ascend-sdk/models/components";

let value: SearchClosedLotsResponse = {};
```
